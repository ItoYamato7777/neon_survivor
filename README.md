# Neon Survivor

Neon Survivorは、ネオン風グラフィックとオートシューティング要素を組み合わせた小規模なアクションゲームです。

プレイヤーは移動とスキルを駆使して敵を倒し、経験値で強化して生き残りを目指します。

■ オンラインでプレイ

このゲームはブラウザでプレイできます：

https://itoyamato7777.github.io/neon_survivor/

## 特徴

- ネオン調のビジュアルとパーティクル表現
- プレイヤーは自動で敵を狙って攻撃（オートアタック）
- スキル（短時間の速度上昇・トレイル表示など）で局面を覆す
- 簡単なローグライト的な成長（経験値・アップグレード）

## 操作方法

- 移動: `W` / `A` / `S` / `D`
- スキル発動: `Space`（クールダウンあり）
- 射撃は近くの敵を自動で狙います（プレイヤーは移動とスキルに集中）

## ローカルでの実行方法

必要条件:

- Python 3.8 以降
- `pygame`（レンダリングと入力に使用）

セットアップ例:

```bash
python -m pip install pygame
python main.py
```

プロジェクトのルートで上記コマンドを実行してください。

## 主要ファイル構成

- `main.py` - ゲームのエントリポイント
- `game.py` - ゲームループと状態管理
- `settings.py` - 各種定数（画面サイズ、色、パラメータ等）
- `entities/` - `player.py`, `enemy.py`, `projectile.py` などのエンティティ実装
- `systems/` - `particle_system.py` などの補助システム
